# Cinema Composer

Веб-приложение для композитинга видео на экран кинотеатра.

Накладывает видео на фоновое изображение кинозала с настройкой тональности, затемнения и прозрачности.

## Установка и запуск

```bash
# 1. Склонировать репозиторий
git clone https://github.com/grayson8geraldo/cinema.git
cd cinema

# 2. Установить зависимости (создаст venv автоматически)
bash setup.sh

# 3. Активировать окружение и запустить
source venv/bin/activate
python3 app.py
```

Откройте **http://localhost:5000** в браузере.

## Требования

- Python 3.10+
- FFmpeg (`sudo apt install ffmpeg` / `brew install ffmpeg`)

## Возможности

- Загрузка фона кинозала, маски экрана и видео через браузер
- Создание маски из координат прямоугольника прямо в интерфейсе
- Настройка параметров: непрозрачность, тональность (тёплая/холодная/нейтральная), затемнение (лёгкое/среднее/сильное)
- Режим превью — быстрый рендер одного кадра (PNG)
- Полный рендер видео (MP4) со скачиванием результата

## CLI-режим

Скрипты можно использовать и без веб-интерфейса:

```bash
# Создать маску
python3 create_mask.py --size 1080x1920 --rect 200,400,880,900 -o mask.png

# Скомпоновать видео
python3 compose.py --bg bg.png --mask mask.png --video input.mp4 -o output.mp4 \
    --tone warm --darkness medium --opacity 0.85
```
